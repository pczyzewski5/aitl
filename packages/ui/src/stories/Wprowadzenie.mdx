# System projektowy AITL

To jest dokumentacja systemu projektowego aplikacji AITL, czyli narzędzia do śledzenia wydatków i planowania miesięcznego budżetu we dwie osoby.

Storybook jest instrukcją obsługi: pokazuje, których elementów użyć, jak je złożyć i jak zachowują się w każdym stanie. Kolejne strony pojawią się razem z tokenami i komponentami.
