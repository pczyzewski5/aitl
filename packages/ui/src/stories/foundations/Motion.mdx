# Ruch

Decyzja z R01.6: prawie bez ruchu. Jedyne ruchy to hover i potwierdzenie po zapisie wpisu. Animacje dekoracyjne są zabronione.

## Hover

## Czego brakuje

Zatwierdzone tokeny nie zawierają reguły dla `prefers-reduced-motion`. To otwarte pytanie do decyzji, a nie zasada. Potwierdzenie po zapisie (widoczne ok. 3 s) powstanie razem z komponentem Toast w etapie 2.
