# System projektowy AITL: start

## Charakter produktu w trzech zdaniach

AITL to praktyczne, czytelne, spokojne i rzeczowe narzędzie, w którym dwie osoby zapisują wpływy i wydatki oraz widzą, ile zostanie w miesiącu, zawsze osobno dla każdego konta bankowego. Wygląd jest stonowany: jasne tło, białe powierzchnie oddzielone ramką, jeden niebieski kolor akcji i prawie bez ruchu. Treść jest po polsku, w trybie rozkazującym, bez ozdobników, a kolor nigdy nie jest jedynym nośnikiem informacji.

Antycharakter: generyczny, korporacyjny lub bankowy, efekciarski, ciasny i nieczytelny, chaotyczny. Źródło: `.ai/specs/design/2026-11-17-referencje.md`.

## Pięć kroków budowy ekranu

1. **Znajdź ekran w specyfikacji i w Storybooku.** Specyfikacje są w `.ai/specs/`. W sekcji "Ekrany" Storybooka sprawdź, czy istnieje podobny ekran, i zacznij od niego. Epiki: [E01](?path=/docs/system-projektowy-epik-e01-dostęp-i-logowanie--docs), [E02](?path=/docs/system-projektowy-epik-e02-zapis-wpływów-i-wydatków--docs), [E03](?path=/docs/system-projektowy-epik-e03-ile-zostanie-w-miesiącu--docs).
2. **Wybierz elementy.** Najpierw element produktu, potem wzorzec, na końcu element bazowy. Pomocą jest [katalog komponentów](?path=/docs/system-projektowy-komponenty-katalog--docs) i strona [Jak wybrać komponent](?path=/docs/system-projektowy-jak-wybrać-komponent--docs).
3. **Dobierz tokeny.** Tylko tokeny znaczeniowe (`--card`, `--muted-foreground`, `--space-panel`, ...), nigdy wartości surowe. Zobacz [Fundamenty](?path=/docs/fundamenty-kolory--docs).
4. **Obsłuż wszystkie stany.** Ładowanie, pusto, błąd, dużo danych, długie teksty i trzy szerokości: 320, 768 i 1440 px. Zasady: [Użycie i dostępność](?path=/docs/system-projektowy-użycie-i-dostępność--docs), [Treść i komunikaty](?path=/docs/system-projektowy-treść-i-komunikaty--docs).
5. **Sprawdź.** `npm run test:storybook` (dostępność blokuje), `npm run check:tokens`, klawiatura i fokus. Przed zgłoszeniem przeczytaj [Czego unikać](?path=/docs/system-projektowy-czego-unikać--docs). Czego brakuje, opisuje [ta strona](?path=/docs/system-projektowy-czego-brakuje--docs); brakującego komponentu nie wymyślamy.
