# EmptyState

Pusty widok: lista, która się załadowała i nie ma w niej nic do pokazania. Źródło reguł: R01.5, R01.7, A1 (referencje), tokeny (`.ai/specs/design/2026-11-17-tokeny.md`), decyzje właściciela z 2026-11-18, WCAG 2.2 i WAI-ARIA. Reguła bez źródła jest oznaczona jako **propozycja** i czeka na decyzję właściciela.

## 1. Do czego służy

Tłumaczy, dlaczego w tym miejscu jest pusto, i podaje następny krok, żeby użytkownik nie myślał, że coś się zepsuło.

## 2. Kiedy używać

- Miesiąc bez wpisów na koncie: "Brak wpisów w tym miesiącu" + "Dodaj wpis" (E02).
- Lista kont na `/`, gdy użytkownik nie ma żadnego konta: tytuł i wyjaśnienie, bez akcji (E01: `EmptyState` gdy pusta).
- Brak kont w sekcji "Ile zostanie" (E03).

## 3. Kiedy nie używać

| Sytuacja | Użyj zamiast |
|---|---|
| Dane się ładują | Skeleton |
| Nie udało się wczytać danych | ErrorState |
| Miesiąc bez wpisów w sekcji "Ile zostanie" | zera w kartach (spec E03: miesiąc bez wpisów pokazuje zera), nie pusty stan |
| Komunikat przy formularzu lub polu | Alert, błąd pod polem w Field |
| Ozdobna strona "witaj" bez treści do pokazania | nie używać |

## 4. Anatomia

1. Tytuł (wymagany): nagłówek `h2`, `h3` (domyślnie) lub `h4` zależnie od miejsca w strukturze strony (prop `titleLevel`), tekst 16 px, waga 600.
2. Opis (opcjonalny): jedno do dwóch zdań, 14 px, `--muted-foreground`, do ok. 65 znaków w linii (`max-w-prose`).
3. Akcja (opcjonalna): jeden przycisk Button w wariancie głównym, z czasownikiem ("Dodaj wpis").

Bez ikony i bez ilustracji (decyzja właściciela, 2026-11-18; A1: bez ozdobników). Treść jest wyrównana do lewej, nie wyśrodkowana. Komponent nie ma własnej ramki ani tła: leży w Card, w panelu albo wprost na stronie. Odstęp między częściami to `--space-within-group` (8 px).

## 5. Warianty

Jeden wygląd, bez wariantów; różnią się zawartością:

| Postać | Kiedy wybrać |
|---|---|
| tytuł + opis + akcja | użytkownik może od razu coś dodać ("Dodaj wpis") |
| tytuł + opis | użytkownik nie może nic zrobić w tym miejscu (brak kont: konto przypisuje się poza tym widokiem) |
| sam tytuł | powód jest oczywisty z kontekstu |

Źródło: decyzja właściciela z 2026-11-18 (jedna akcja przez Button, bez ikony); wybór postaci wynika z E01 i E02.

## 6. Stany

| Stan | Wygląd |
|---|---|
| Domyślny | tytuł, opcjonalnie opis i przycisk |
| Najechanie, fokus, wciśnięty | tylko przycisk akcji (jak w Button) |
| Zablokowany | nie dotyczy: akcja albo jest dostępna, albo jej nie pokazujemy (bez wyjaśnienia nie ma blokady) |
| Ładowanie | to osobny stan widoku (Skeleton), nie EmptyState |
| Wybrany | nie dotyczy |
| Błąd | to ErrorState |

## 7. Zachowanie i dostępność

- Rola: **brak roli live** (decyzja właściciela, 2026-11-18). Pusty stan jest zwykłą treścią strony, nie komunikatem o zdarzeniu; czytnik ekranu trafia na nagłówek podczas przeglądania. Nie dodawaj `role="status"` ani `aria-live`.
- Nagłówek: poziom `h2`-`h4` pasuje do struktury strony (nie przeskakuj poziomów, WCAG 1.3.1). W karcie z tytułem `h2` pusty stan ma `h3`.
- Klawiatura: `Tab` wchodzi na przycisk akcji, `Enter` i spacja go wywołują.
- Kolejność fokusu: jedyny element interaktywny to przycisk.
- Kontrast: tytuł `--foreground` na `--card` 14,68:1, opis `--muted-foreground` na `--card` 7,56:1 (na tle strony 6,87:1).
- Cel kliknięcia: przycisk ma 36 px wysokości (`--control-height`), więcej niż minimum 24 px (WCAG 2.5.8).
- Znaczenie niesie tekst, nie ikona ani kolor (A3).

## 8. Treść

Zasada: **dlaczego pusto i co zrobić**, rzeczowo, bez wykrzykników (R01.7).

- Tytuł: stwierdzenie faktu, jedno zdanie: "Brak wpisów w tym miesiącu", "Nie masz dostępu do żadnego konta bankowego".
- Opis: następny krok albo wyjaśnienie: "Dodaj pierwszy wpływ albo wydatek, żeby zobaczyć, ile zostanie."
- Akcja: czasownik + obiekt: "Dodaj wpis" (nie "OK", nie "Dalej").
- Zabronione: "Nic tu nie ma!", "Puściutko", ikony i emoji, marketing.
- Długość: tytuł do ok. 60 znaków, opis do 2 zdań; dłuższy tekst zawija się (`wrap-anywhere`), nie obcinaj.
- Przykłady są oznaczane "(przykład)" w nazwach kont i wpisów (A5).
- Tłumaczenie na dłuższy język: wysokość jest elastyczna, przycisk zawija etykietę.

## 10. API

| Prop | Typ | Domyślnie | Opis |
|---|---|---|---|
| `title` | `string` | | tytuł (wymagany); tekst przekazuje aplikacja, komponent go nie zawiera |
| `description` | `string` | | opis (opcjonalny) |
| `action` | `{ label: string; onClick: () => void }` | | akcja; bez niej nie ma przycisku |
| `titleLevel` | `'h2' \| 'h3' \| 'h4'` | `'h3'` | poziom nagłówka tytułu |
| `className` i atrybuty `div` | `ComponentProps<'div'>` | | `className`, `id`, `data-*` (bez `title`, bo to tytuł komponentu) |

## 11. Kod

Minimalny przykład:

```tsx
import { EmptyState } from '@aitl/ui';

<EmptyState title="Brak kont" />;
```

Typowy przykład z produktu, pusty miesiąc na koncie:

```tsx
import { Card, CardContent, CardHeader, CardTitle, EmptyState } from '@aitl/ui';

<Card>
  <CardHeader>
    <CardTitle as="h2">Konto wspólne</CardTitle>
  </CardHeader>
  <CardContent>
    <EmptyState
      title="Brak wpisów w tym miesiącu"
      description="Dodaj pierwszy wpływ albo wydatek, żeby zobaczyć, ile zostanie."
      action={{ label: 'Dodaj wpis', onClick: openEntryForm }}
    />
  </CardContent>
</Card>;
```

## 13. Powiązane

- Z czym się go myli: ErrorState (nie udało się wczytać, a nie "nic nie ma"), Skeleton (jeszcze się ładuje), Alert (komunikat przy formularzu), Card (powierzchnia, w której pusty stan leży).
- Występuje we wzorcach: lista wpisów konta (E02), lista kont (E01), sekcja "Ile zostanie" (E03). Wzorzec listy z filtrami (etap 3) rozróżni "brak wyników dla filtrów" od "jeszcze nic tu nie ma".

## Czego brakuje

- Ikona lub ilustracja: wykluczone decyzją właściciela (2026-11-18); do ponownej oceny razem z luką L5 (ikony).
- Akcja jako link (nawigacja zamiast przycisku) i druga akcja: poza zakresem; jedna akcja przez Button.
- Wersja "brak wyników dla filtrów" z akcją "Wyczyść filtry": dojdzie z wzorcem listy z filtrami (etap 3).
- Własna powierzchnia (ramka, tło) dla pustego stanu poza kartą: brak ekranu; dziś leży w Card albo bezpośrednio na stronie.
- Przeniesienie fokusu na pusty stan po usunięciu ostatniego wpisu: wzorzec formularza i listy (etap 3).
